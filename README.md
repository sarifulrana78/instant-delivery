# FlashDash: Premium Instant Delivery System

A state-of-the-art interactive simulated instant delivery dashboard featuring real-time tracking, customer, rider, and admin roles. Built using React, Vite, and modern CSS glassmorphism.

## Tech Stack
- Frontend: React (Vite)
- Styles: Vanilla CSS (Custom Design System, Glassmorphism, Responsive Grid)
- Mapping: Animated Live SVG Map Simulation

## Key Features
- **Store Browser & Cart Checkout**: A customer view to shop from various simulated stores.
- **Real-Time Live Tracker**: Watch the rider move across a beautiful, interactive SVG map layout in real-time.
- **Rider Simulator Control**: Change speeds, trigger traffic events, update rider status manually, and trigger simulated chat updates.
- **Admin Analytics Dashboard**: Metrics tracking active deliveries, average response times, revenues, and ratings.
- **Premium Aesthetics**: Dark mode, gorgeous animations, audio notifications, and sleek glass design.
